# Lesson 2.1 — Number Series, Coding–Decoding and Odd Man Out
Welcome! This lesson covers number series, letter positions, coding and decoding, and odd man out.
Number series follow a hidden rule. Test the common patterns in order: differences, ratios, squares and cubes, mixed operations, and alternate terms.
Start with differences. In 2, 6, 12, 20, 30 the differences are 4, 6, 8, 10, rising by 2. So the next difference is 12, and the next term is 42. || Start with differences. In two, six, twelve, twenty, thirty, the differences are four, six, eight, ten, rising by two each time. So the next difference is twelve, and the next term is forty-two.
If differences don't work, try ratios. In 3, 9, 27, 81 each term is 3 times the one before, so the next term is 243. || If the differences don't work, try ratios. In three, nine, twenty-seven, eighty-one, each term is three times the one before. So the next term is two hundred and forty-three.
Look for squares and cubes. 2, 5, 10, 17, 26 is n² + 1: 1, 4, 9, 16, 25, each plus one. The next term is 37. || Look for squares and cubes. Two, five, ten, seventeen, twenty-six is n squared plus one. One, four, nine, sixteen, twenty-five, each plus one. So the next term is thirty-seven.
Some series alternate two operations. 5, 10, 7, 14, 11 goes ×2, −3, ×2, −3. So the next term is 22. || Some series alternate two operations. Five, ten, seven, fourteen, eleven goes times two, minus three, times two, minus three. So the next term is twenty-two.
For letters, use positions: A = 1, B = 2, … Z = 26. Remember EJOTY: E = 5, J = 10, O = 15, T = 20, Y = 25. || For letters, use positions. A is one, B is two, all the way to Z, twenty-six. Remember the word E J O T Y. E is five, J is ten, O is fifteen, T is twenty, and Y is twenty-five.
The reverse position is 27 minus the position, so A pairs with Z, B with Y, and M with N. Opposite letters always add up to 27. || The reverse position is twenty-seven minus the position. So A pairs with Z, B with Y, and M with N. Opposite letters always add up to twenty-seven.
In coding questions, find the rule from the example. If FISH is written as GJTI, every letter moves forward by one. So BIRD becomes CJSE. || In coding questions, find the rule from the example. If FISH is written as G J T I, every letter moves forward by one. So BIRD becomes C J S E.
Other common rules: replace each letter with its opposite, so GOLD becomes TLOW. Or write the word backwards, or use position numbers. || Other common rules. Replace each letter with its opposite, so GOLD becomes T L O W. Or write the word backwards, or replace letters with their position numbers.
For odd man out, find the property all but one share. In 27, 64, 125, 144, 216, all are cubes except 144, which is 12². || For odd man out, find the property that all but one share. In twenty-seven, sixty-four, a hundred and twenty-five, a hundred and forty-four, and two hundred and sixteen, all are cubes except a hundred and forty-four, which is twelve squared.
Try this: what comes next in 1, 2, 6, 24, 120? The multipliers are ×2, ×3, ×4, ×5, so next is ×6: 720. || Try this. What comes next: one, two, six, twenty-four, a hundred and twenty? The multipliers are two, three, four, five. So next we multiply by six, which gives seven hundred and twenty. The answer is A.
