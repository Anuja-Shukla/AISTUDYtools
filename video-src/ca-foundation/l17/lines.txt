# Lesson 1.7 — Sets, Relations, Functions, Limits and Continuity
Welcome! This lesson covers sets, relations and functions, and the basic ideas of limits and continuity.
A set is a well-defined collection of objects, like the vowels {a, e, i, o, u}. You can list the elements, or describe them by a rule. || A set is a well-defined collection of objects, like the set of vowels. You can list the elements, or describe them by a rule.
Key ideas: the empty set, subsets and the universal set. The power set is the set of all subsets. A set with n elements has 2ⁿ subsets, so {1, 2, 3} has 8. || Key ideas: the empty set, subsets, and the universal set. The power set is the set of all subsets. A set with n elements has two to the n subsets. So the set one, two, three has eight.
Union A ∪ B: in either set. Intersection A ∩ B: in both. Difference A − B: in A but not B. Complement A′: everything outside A. || The union, A union B, has elements in either set. The intersection, A intersection B, has elements in both. The difference, A minus B, is in A but not in B. And the complement of A is everything outside A.
To count a union, never count the overlap twice: n(A ∪ B) = n(A) + n(B) − n(A ∩ B). || To count a union, never count the overlap twice. n of A union B equals n of A, plus n of B, minus n of A intersection B.
In a class of 100, 60 like Accounts, 50 like Economics and 20 like both. So 60 + 50 − 20 = 90 like at least one, and 10 like neither. || In a class of a hundred, sixty like Accounts, fifty like Economics, and twenty like both. So sixty plus fifty minus twenty, ninety, like at least one. And ten like neither.
De Morgan's laws: the complement of a union is the intersection of the complements, and the complement of an intersection is the union of the complements. || De Morgan's laws. The complement of a union is the intersection of the complements. And the complement of an intersection is the union of the complements.
The Cartesian product A × B is the set of all ordered pairs, with n(A) × n(B) elements. Any subset of it is a relation. Reflexive, symmetric and transitive together make an equivalence relation. || The Cartesian product, A cross B, is the set of all ordered pairs. It has n of A times n of B elements. Any subset of it is a relation. A relation that is reflexive, symmetric and transitive is called an equivalence relation.
A function gives every input exactly one output. It is one-one if different inputs give different outputs, onto if every value is reached, and it has an inverse when it is both. || A function gives every input exactly one output. It is one-one if different inputs give different outputs. It is onto if every value in the co-domain is reached. And when it is both, it has an inverse.
For f(x) = 2x + 3: f(4) = 11. To invert, write y = 2x + 3 and solve for x: f⁻¹(x) = (x − 3) ÷ 2. || For f of x equals two x plus three, f of four is eleven. To invert it, write y equals two x plus three, and solve for x. The inverse is x minus three, over two.
A limit is the value f(x) approaches as x approaches a point. For a 0/0 form, simplify first: (x² − 4)/(x − 2) = x + 2, so the limit as x → 2 is 4. || A limit is the value f of x approaches as x approaches a point. For a zero over zero form, simplify first. x squared minus four, over x minus two, is just x plus two. So as x approaches two, the limit is four.
Two standard results: (xⁿ − aⁿ)/(x − a) → naⁿ⁻¹ as x → a, and (1 + 1/n)ⁿ → e as n grows. || Two standard results. x to the n minus a to the n, over x minus a, approaches n times a to the n minus one, as x approaches a. And one plus one over n, to the power n, approaches e as n grows.
A function is continuous at a point if its limit there equals its value: f(a) exists, the limit exists, and they are equal. Its graph has no break. || A function is continuous at a point if its limit there equals its value. The value exists, the limit exists, and they are equal. In other words, the graph has no break.
Try this: if n(A) = 3 and n(B) = 4, how many relations are there from A to B? A × B has 12 pairs, so there are 2¹² = 4,096 relations. || Try this. If A has three elements and B has four, how many relations are there from A to B? A cross B has twelve pairs, so there are two to the twelve, four thousand and ninety-six, relations. The answer is A.
