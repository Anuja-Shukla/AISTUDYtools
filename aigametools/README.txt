AIgametools for AIStudyTools
============================
Upload this whole "aigametools" folder to the top level of the AIStudyTools
GitHub repository (next to index.html). The game will then open at
https://aistudytools.com/aigametools/

Everything it needs is inside this folder. It works on a plain HTML site and on
a Jekyll site. To show it in your menu, add a link to /aigametools/ in the nav.
Third-party library licences are in vendor/LICENSES.txt.
